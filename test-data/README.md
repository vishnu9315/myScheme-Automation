# test-data/

Reserved for larger external fixture data (e.g. a JSON file of scheme
slugs, or a CSV of filter-combination cases) if this framework's coverage
grows enough to need data-driven tests loaded from a file rather than
inline objects.

Today's test data is small enough to live directly in `utils/testData.ts`
— nothing has been added here yet, and this directory exists to make room
for that growth without needing to restructure the framework later.
